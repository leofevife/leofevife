## 🚀 Sobre Mim

- 🤖 **Engenharia de IA & LLMs:** Desenvolvimento de sistemas RAG com busca vetorial híbrida, embeddings densos (`BAAI/bge-m3`), **LangChain**, **Qdrant** e avaliação automatizada com **RAGAS**.
- 📊 **Ciência de Dados & Machine Learning:** Análise exploratória (EDA), engenharia de atributos, modelagem preditiva supervisionada e não supervisionada (`scikit-learn`, `pandas`, `numpy`) e dashboards interativos (**Streamlit**).
- 💻 **Desenvolvimento Full-Stack:** Arquitetura de APIs RESTful com **FastAPI** e **Flask** integradas a interfaces reativas em **Vue 3**, **TypeScript**, **Vuetify** e **Tailwind CSS**.
